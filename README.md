# 代工厂物料台账

记录「我存在代工厂的物料还有多少」的本地小工具。全部数据存在你自己的电脑上，不联网、不注册、不上传。

## 怎么启动

双击 **`启动.bat`**。

需要电脑上有 Python 3（一般装过就有）。如果双击没反应，看下面的「打不开怎么办」。

> **第一次用，先清掉演示数据**
> 现在里面塞了几条假的示例（不锈钢板、纸箱等），是给你看效果用的。
> 双击 **`清空演示数据.bat`**，它会把这些挪到 `旧数据\` 文件夹里（不直接删，反悔还能拿回来），
> 然后重新打开程序，就是一个干干净净的空账本。
> 建议顺序：先清空 → 去「材料字典」建你自己的材料 → 去「代工厂」建厂 → 开始记账。

## 五个页签

### 1. 库存总览
打开就能看见：每种材料现在还剩多少，分别存在哪个厂。
- 点材料前面的小三角能展开，看到**每个厂各存了多少**。
- 开了「区分良品/不良品」的材料，会显示 **良品 xx ／ 不良品 xx**，
  括号里是总数（总数 = 良品 + 不良品）。
- 红色那行 = 该材料的总结存已经低于你设的安全库存，该补货了。
- 上面四个数字：在册材料 / 代工厂 / 有结存的材料 / 有效流水笔数。
- 右上「排序」可以按材料名、结存多少、最近变动排。
- 右上「导出库存」把当前这张表存成 Excel 能直接打开的 CSV。

### 2. 出入库（日常主要用这页）
记一笔就填这张表：

| 类型 | 什么时候用 |
|---|---|
| **入库** | 往代工厂送了料 |
| **消耗** | 生产用掉了料 ← 你说的“扣减”就是这个 |
| **退回** | 料从代工厂拉回来了 |
| **盘点** | 实地数了一遍，填实际数量，系统自动算差额 |

- 选好材料，右边会显示**该厂当前结存**，方便你核对着填。
- 数量填正数就行，加减由类型决定，不用自己带负号。
- 时间默认现在，可以改成补记的日期。
- 如果消耗的数量超过现有结存，会弹窗让你确认，防止手滑多打一个零。
- 提交后下面「今天记的账」立刻刷新，记错了当场就能作废。

### 3. 流水明细
所有历史记录都在这。可以按时间段（今天/本月/全部/自选）、类型、材料、代工厂、关键词筛。
- 结算行在最底下：共多少条、总共入多少、出多少。
- 选中一条点「作废」，结存立刻回滚（不是删除，痕迹还在，选「含已作废」能看到）。
- 作废错了可以「恢复选中」。
- 「导出 CSV」按当前筛选条件导出。

### 4. 材料字典
先把材料建好，出入库时才能选。
- 材料名 + 规格 唯一确定一种料（比如「不锈钢板 / 304 / 2mm」和「不锈钢板 / 304 / 3mm」是两种）。
- **安全库存**：低于它就变红提醒。留空 = 不提醒。
- **区分良品 / 不良品**（可选）：勾上后，记每一笔账时可以选这笔是良品还是不良品，
  总览里会分别统计。**仓库总数始终 = 良品 + 不良品**，两个数字不会互相打架。
  不勾就是普通记法，跟以前完全一样。
- 不用了的材料点「停用」，下拉框里就不出现了，但历史记录和结存都保留。

**关于良品/不良品的几个细节**：
- 默认**不勾选**，所以老材料、老数据不受任何影响。
- 盘点时按「同品质」算差额——盘良品不会把不良品的数量算成差异。
- 消耗时如果超过该品质的结存，会单独提示（比如「良品的结存只有 50，你要扣 80」）。
- 后来想关掉也行：已记的品质数据保留，只是之后不再让你选。

### 5. 代工厂
记录厂名、联系人、备注。停用的厂同样只是从下拉框隐藏。

### 6. 云端备份（可选，默认关闭）
**这个功能完全可以不用，本地记账一直都能用。**

打开后，每次记账保存都会在后台把这个账本的 CSV 快照传一份到你自己的备份柜，
相当于多一层保险。传失败只影响备份，绝不影响本地数据。

![云端备份-未配置](截图/7-云端备份-未配置.png)

设置步骤：
1. 填「备份地址」（形如 `https://xxx.example.com`，不用带 `/api`）
2. 填「访问密码」
3. 勾上「启用云端备份」
4. 点「保存设置」
5. 点「测试连接」，看到「连接正常」就通了

几个开关的意思：

| 控件 | 作用 |
|---|---|
| **启用云端备份** | 总开关。关着的时候程序完全不会联网 |
| **记账后自动上传** | 开着＝每次记完账自动传；关掉＝只在你点按钮时传 |
| **上传内容** | 「全部数据」含库存+材料+代工厂+全部流水；「只要当前库存」更小 |
| **立即备份一次** | 不管开关状态，当场传一次 |
| **测试连接** | 只登录看云端有几个文件，不传数据 |

**关于文件名**：每次备份用带时间戳的新名字（如 `代工厂物料台账_20261112_053041.csv`），
所以在网页上能看到一串按时间排列的历史备份，想回到某个时刻的账就下那一份。

**关于凭据**：地址和密码存在本地 `data\inventory.db` 的 `settings` 表里，
不写进任何源码或配置文件，导出的 CSV 里也不会带出去。想彻底断开就清空地址或关掉开关。

## 数据存在哪

```
data\inventory.db          ← 你的全部数据，就这一个文件
data\backups\              ← 每次关窗口自动备份，留最近 30 份
```

**备份方法**：直接复制 `data` 整个文件夹到你 U 盘或网盘就行。
**换电脑**：把 `data` 文件夹拷过去，放在程序同目录下即可。
**恢复**：把 `data\backups\` 里某一份 `.db` 改名为 `inventory.db` 覆盖回去。

## 打不开怎么办

1. 命令行进到这个文件夹，运行 `python main.py`，看报错信息。
2. 报错内容也会自动记到 `data\error.log`。
3. 最常见的原因是没装 Python。装的时候记得勾上 **Add Python to PATH**。

| `test_cloud.py` | 备份逻辑自测，`python test_cloud.py` 可跑 |
| `test_ui.py` | 界面冒烟测试，`python test_ui.py` 可跑 |
| `_seed_demo.py` | 塞演示数据（正式用前先删掉 data 文件夹再重启就是空的） |
| `csv-backup/` | 备份柜服务端的源码（跟这个记账程序无关，可删） |

## 一个设计上的说明

**库存数字不是单独存的，是由所有流水加出来的。**

好处是：流水和结存永远对得上，不可能出现「改了流水但库存忘了改」这种账实不符。任何一条记错了，作废它，结存自动跟着回滚。

代价是：流水特别多（几万条以上）时，总览会稍慢一点。正常小厂用量几年内不会有这个问题。
